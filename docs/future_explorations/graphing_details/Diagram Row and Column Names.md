# Diagram Row- and Column Names

6-27-26

Current naming reflects each renderer’s semantic story:

Scenario-flow:
horizontal progression is called bands
vertical strata are lanes: Steps, Places, View States
branch alternatives are tracks
cells combine lane + band + track

Outcome-opportunity:
horizontal categories are explicitly columns: Initiatives, Opportunities, Outcomes, Metrics
vertical grouping around an outcome is called a band
stacked rows inside a band are physicalSlots
cells combine column + band + slot

Service-blueprint:
horizontal progression uses bands and physical columns
vertical strata are lane shells/guides
cells combine lane + column
